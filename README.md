Inventory Management System

A Java backend project developed as part of my software engineering journey, focused on building a scalable and maintainable inventory management system using modern backend development practices.

The project has evolved from a simple console application into a structured backend application, progressively incorporating professional software engineering principles, database management, and modern Java technologies.
